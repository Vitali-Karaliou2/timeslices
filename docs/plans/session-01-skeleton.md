# Сессия 01. Скелет оболочки

Ветка: `session-01-skeleton`. Ожидаемый результат — PR в `main`, который можно собрать,
запустить и прогнать тесты в облачной сессии и на локальной машине.

## Задача
Создать скелет ASP.NET Core приложения-оболочки по CLAUDE.md и docs/spec/shell-spec.md.
Никакого содержания коллекции, кроме одного фиктивного среза `cpu-cycle` и одного
`static-page-1995` с пустыми примерами — ровно столько, чтобы работала навигация по графу.

## Шаги
1. `dotnet new sln -n TimeSlices`; `dotnet new razor -n TimeSlices.Web -o src/TimeSlices.Web --auth Individual`
   (Identity + SQLite из шаблона); `dotnet new xunit -n TimeSlices.Tests -o tests/TimeSlices.Tests`;
   добавить проекты в решение; `.gitignore` для dotnet (`dotnet new gitignore`).
2. Роли `Learner`, `Examiner`, `Admin`; сидирование трёх dev-пользователей при старте
   в Development (логины и пароли — в `appsettings.Development.json`, не в коде).
3. Слой содержания: `ContentLoader`, который читает `Content/tracks.json` и `Content/slices/*/slice.json`,
   строит DAG, проверяет отсутствие циклов при старте (падать с понятной ошибкой).
4. Сущности EF: `UserSliceState` (пользователь × тематический срез × состояние из brief 5.3,
   пока только три состояния: Unavailable, Available, InProgress, Done), `Attempt` — пока не нужен.
5. Страницы: `/` (главная: треки и срезы с состояниями для текущего пользователя),
   `/slices/{id}` (страница среза: поля brief 7.1, список примеров, кнопки «Готово» и «Далее»),
   `/slices/{id}/examples/{exampleId}` (пример: iframe на `entry` выбранной реализации,
   выпадающий список реализаций, код для показа, процесс — пока только список кадров).
6. Тесты (xUnit) по docs/acceptance.md: граф без циклов; срез недоступен, пока не пройдены
   предшественники; «Готово» переводит в Done и открывает следующий; повторное прохождение
   без сброса не ломает последующие.
7. `dotnet build`, `dotnet test` — зелёные. Коммит, пуш, PR. Отчёт по скиллу `session-report`.

## Не делать в этой сессии
Контроль знаний, экзаменатор, эмуляция, процессы с проигрыванием кадров, оформление.

## Итог

### 1. Сделано
- Решение `TimeSlices.sln` (.NET 10 LTS): `src/TimeSlices.Web` (Razor Pages + Identity + EF Core/SQLite из
  шаблона), `tests/TimeSlices.Tests` (xUnit). Bootstrap и jQuery из шаблона убраны.
- Роли Learner, Examiner, Admin. Три dev-пользователя сидируются в Development, логины и пароли лежат
  в `appsettings.Development.json`. Без входа открыта только страница входа и регистрации.
- Слой содержания `Collection/`:
  - `ContentLoader` читает `tracks.json`, `slices/*/slice.json` и манифесты, проверяет ссылки, пути
    манифеста и отсутствие циклов;
  - при ошибке приложение не стартует и пишет, например: «цикл в графе срезов: a → b → a»;
  - `ContentCatalog` хранит DAG тематических срезов (срез × трек).
- Состояния `Progress/SliceProgressService`:
  - в БД хранятся только `InProgress` и `Done`, а `Unavailable` и `Available` вычисляются по графу;
  - работают «Готово» и «Далее» (с выбором, если следующих несколько);
  - повторное прохождение — со сбросом последующих или без, с пометкой «повторно».
- Страницы:
  - `/` — треки и срезы с состояниями;
  - `/slices/{id}` — поля brief 7.1, примеры, кнопки;
  - `/slices/{id}/examples/{exampleId}` — iframe, выпадающий список реализаций, код для показа,
    список кадров процессов;
  - `/admin` — пользователи и их состояния.
- Сборки примеров отдаются по `/content/{token}/…`, только из папок `implementations/<id>/` и только
  по токену реализации, срез которой открыт пользователю (ADR 0002).
- Содержание: треки `hardware` и `frontend`, фиктивные срезы `cpu-cycle` и `static-page-1995` с примерами-заглушками.
- Вне плана: `scripts/install_dotnet.sh` получил запасной путь — пакет `dotnet-sdk-10.0` из Ubuntu.
  В облачной среде сетевая политика блокирует `builds.dotnet.microsoft.com`, и хук SessionStart
  оставлял сессию без dotnet. Изменение вынесено в отдельный коммит.

### 2. Сознательно не сделано и почему
- Контроль знаний, экзаменатор, эмуляция, проигрывание кадров и оформление исключены планом.
  Процесс показан только списком кадров.
- `Attempt`, `Question` и `Answer` не созданы: по spec они не входят в сессию 01.
- HTTP-автотестов нет (маршрут `/content`, авторизация страниц, редиректы). Для них нужен
  `Microsoft.AspNetCore.Mvc.Testing` — новая зависимость, жду согласия. Пока это проверено вручную
  (раздел 3). Поэтому `dotnet test` покрывает пункты 3–6 acceptance на уровне сервисов, а не страниц.
- Защита от гонки при двойном «Готово» (повтор после `DbUpdateException`) написана, но не покрыта тестом:
  гонку в SQLite в памяти не воспроизвести детерминированно.
- Подсветки «ключевых строк» в коде нет: в манифесте это свободный текст `note`, и я не стал выдумывать
  его формат. Пометка показывается рядом с кодом.
- Отдельная страница `Next` не делалась: выбор показывается на странице среза.

### 3. Проверка
- `dotnet build TimeSlices.sln` прошёл без ошибок и предупреждений.
- `dotnet test TimeSlices.sln`: `Passed! - Failed: 0, Passed: 27, Skipped: 0, Total: 27`.
- `python3 scripts/validate_manifest.py` на `tracks.json`, двух `slice.json` и двух `manifest.json`: все OK.
- `dotnet run --project src/TimeSlices.Web`, проверка curl и Playwright (Chromium):
  - `/` без входа даёт 302 на вход. Learner, Examiner и Admin входят и видят треки;
  - `static-page-1995` показан «Недоступен». Прямой URL среза — 403 без содержания, URL примера —
    редирект на срез;
  - «Готово» на `cpu-cycle` переводит его в «Пройден», а `static-page-1995` — в «Доступен». «Далее»
    ведёт на него;
  - повторное открытие `cpu-cycle` показывает выбор. «Не менять» даёт «В процессе (повторно)», а
    последующий остаётся открыт. «Сбросить» делает последующий «Недоступен»;
  - пример в iframe отрисован, CSS из сборки применяется (проверено во временной копии содержания
    со стилем). Код и кадры видны;
  - `/content/**` без токена, с подделанным токеном или токеном другой реализации, а также
    `manifest.json`, `slice.json`, `tracks.json` и `..` дают 404. Реализация, «отыгранная вперёд»
    на недоступный срез, в списке не видна, а `?impl=` на неё даёт 404;
  - при цикле в графе (временная копия содержания) приложение не стартует:
    `ContentLoadException … цикл в графе срезов: cpu-cycle → static-page-1995 → cpu-cycle`.
- Субагенты:
  - `code-reviewer`: один блокер (анонимная отдача `/content`) и замечания. Исправлено, повторная
    проверка нашла показ «отыгранных вперёд» реализаций — тоже исправлено;
  - `era-reviewer`: см. раздел 4.

### 4. Допущения, принятые за автора
- .NET 10 (LTS на 17.10.2026) вместо неуказанной версии. `.sln`, а не `.slnx`, как в CLAUDE.md.
- `app.db` создаётся в папке проекта `src/TimeSlices.Web/`: при `dotnet run` текущей папкой становится
  она, а в CLAUDE.md сказано «в корне». Файл в .gitignore.
- Открытие доступного среза (GET) переводит его в «В процессе». Повтор пройденного среза — только по
  кнопке, а не простым открытием, хотя brief 5.3 можно прочитать буквально (обоснование в ADR 0002).
- Подписи интерфейса («Недоступен», «Пройден», «Готово», «Далее», «Сбросить последующие», «Куда дальше»
  и т. п.) — черновики формулировок. Отдельной пометкой `ЧЕРНОВИК` они в интерфейсе не помечены.
- Содержание заглушек:
  - описания треков и все тексты срезов помечены `ЧЕРНОВИК`;
  - HTML-заглушки на английском (ASCII), чтобы не решать за вас вопрос кодировок 1995 года;
  - `relevance` у обоих срезов `b` (из примера схемы). era-reviewer считает, что возможно `a`. Решать вам.
- `ПРОВЕРИТЬ ДАТУ`:
  - **`cpu-cycle`: 1945–1949.** Ориентиры: отчёт по EDVAC 1945, Manchester Baby 1948, EDSAC 1949.
    Границы и терминология («выборка — декодирование — исполнение», набор регистров) — за вами;
  - **`static-page-1995`: 1994–1996** (взято из примера схемы). era-reviewer: к 1996 году уже были
    JavaScript (Netscape 2.0) и CSS (IE 3.0), а это противоречит «без скриптов и без CSS». Возможно,
    `yearTo` = 1995;
  - **«HTML 2.0» применительно к 1994 году.** RFC 1866 вышел в ноябре 1995. В текстах среза сейчас
    этого нет, но в будущем это анахронизм названия;
  - **linkForward «формы и первая динамика (1999)».** `<FORM>` и CGI существовали уже в 1993–1995.
    Формулировка может ввести в заблуждение;
  - **обоснование ребра `cpu-cycle → static-page-1995`** («что такое клиент, сервер и файл») не следует
    из среза 1945–1949. Само межтрековое ребро — моё предложение, его утверждаете вы.
- HTML-заглушка в срезе `cpu-cycle` формально анахронична (HTML ~1991). Её нужно заменить до снятия `draft`.
- `RequireConfirmedAccount = true` оставлен из шаблона. Самостоятельно зарегистрированный пользователь
  без отправителя писем подтверждает адрес по ссылке, которую показывает страница Development. В
  Production первого Admin пока создать нечем.

### 5. Черновик ADR
`docs/decisions/0002-shell-skeleton-states-and-content-access.md` (proposed): вычисляемые состояния,
повтор по явному действию, доступ к сборкам по токену реализации, проверка путей манифеста, `Collection/`
вне `Content/`, .NET 10 и `.sln`.
