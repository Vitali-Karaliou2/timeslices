## Часть 2. Пример «Справочник» (`directory`)
1. **Где лежит.** `Content/slices/net-before-web-1992/examples/directory/` (пример вводится в net-01,
   `introducedInSlice: "net-before-web-1992"`, `complexity: 1`). В `examples` обоих срезов —
   `["directory"]`. Пример `stub-static-page` **удалить** вместе с папкой: его заменяет `directory`.
2. **Реализации** (поля манифеста — по разделу 5 описаний):
   - `ftp-1992` (`slice: net-before-web-1992`, `codeMode: emulated`): имитация терминала —
     `index.html` + небольшой JS, который показывает сеанс по шагам по нажатию Enter или кнопки
     «Следующая команда». Код для показа — `code/session.txt` (расшифровка сеанса, 25–35 строк).
   - `gopher-1992` (`slice: net-before-web-1992`, `codeMode: emulated`): имитация текстового меню
     с выбором пунктов цифрами; переходы по пунктам 1–4, справочник CCSO отвечает на «Иванов».
     Код для показа — `code/menu.txt` (сырые строки меню, поля через табуляцию).
   - `web-1995` (`slice: static-page-1995`, `codeMode: executable`): `index.html` на HTML 2.0 +
     `<table>`, с `<img>` (GIF) в тексте и ссылкой на страницу другой кафедры **внутри предложения**.
     «Другую машину» изобрази второй страницей в той же сборке (`chem/index.html`) и относительной
     ссылкой; в стоп-кадре 7 и в `note` кода объясни, что в 1995 году здесь был бы адрес другого
     сервера. GIF сделай сам (скриптом, без новых зависимостей), 1–2 КБ. Код для показа —
     `code/index.html`, **тот же файл**, что исполняется.
   - JS имитаций — средство визуализации: комментарий «средство визуализации, не код эпохи» в начале
     каждого такого файла (CLAUDE.md). Без внешних библиотек и CDN.
3. **Процессы** — три файла по разделу 6 описаний: `ftp-session`, `gopher-menu`, `request-response`.
   Время кадров — в `at` (ISO), длительности — в `durationNote`; у стоп-кадров `stop: true` и `detail`
   с `codeFile`, `lines` и `explanation` (текст пояснения стоп-кадра из описания, с `ЧЕРНОВИК:`).
4. **Вопросы** — `questions.json` для `net-before-web-1992` и `static-page-1995`, по пять, из раздела 7
   описаний: `prompt`, `referenceReasoning`, `followUpTemplate` (с `{answer}`).
5. `python3 scripts/validate_all.py` после каждого блока файлов.

## Часть 3. Проверка и PR
1. `dotnet build`, `dotnet test`, `python3 scripts/validate_all.py` — зелёные.
2. Вручную (`dotnet run`, обучаемый): у `net-before-web-1992` на странице примера две реализации
   в списке, обе работают в iframe; после «Готово» на net-01 у `static-page-1995` открывается
   `web-1995`, картинка и ссылка на вторую страницу работают внутри iframe.
3. `era-reviewer` — **на трёх реализациях** (это первое настоящее содержание): `code/session.txt`,
   `code/menu.txt`, `code/index.html`; JS имитаций не проверяется. Его замечания — в отчёт с
   `ПРОВЕРИТЬ ДАТУ`, сам даты не исправляй. Затем `code-reviewer`.
4. Отчёт по скиллу `session-report` в `## Итог` этого файла; PR в `main`.
