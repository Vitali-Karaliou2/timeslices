## Часть 1. Правки по итогам сессии 05 (первыми коммитами)
1. **`web-1995`, стоп-кадр 1** процесса `request-response`: пояснение — дословно из раздела 6
   описания fe-01 (имени машины в запросе нет; `Host` — с HTTP/1.1, 1997); `detail` — на строку запроса
   в `code/http.txt`.
2. **Пометка «ЧЕРНОВИК» в интерфейсе.** В файлах содержания префикс `ЧЕРНОВИК:` остаётся. Оболочка
   при показе убирает его из текста и вместо этого показывает **один значок «черновик»** у блока
   (у поля среза, у кадра процесса, у вопроса). Правило показа — в одном месте кода оболочки, с тестом.
3. **Пояснение стоп-кадра — один раз.** Сейчас оно видно трижды (строка состояния, список кадров,
   панель стоп-кадра). Оставь его в панели стоп-кадра; в строке состояния — «Стоп-кадр N из M»;
   в списке кадров — текст кадра и ссылка на код, без пояснения. Без JS пояснение видно в списке.

## Часть 2. Срез `cpu-cycle`
1. **`slice.json`** — по разделам 0, 2, 4 описания: `relevance: "a"`, `introduces`, `linkBack`,
   `linkForward`, `whyNeededToReviewModelCode` дословно; `examples: ["squares"]`.
2. **Удали заглушку `stub-cpu-cycle`.**
3. **Пример `squares`** в `Content/slices/cpu-cycle/examples/squares/`, `introducedInSlice: "cpu-cycle"`,
   `complexity: 1`. Обе реализации — `slice: "cpu-cycle"`, `codeMode: "emulated"`.
4. **`eniac-1946`**: схема панелей (статический HTML и немного JS для переключателя «10 / 100»),
   машина не эмулируется. `code/setup-sheet.txt` — лист настройки, реконструкция по ADR 0007
   (`anachronismCheck.notes` — об этом). Переключатель показывает, какие строки листа настройки меняются.
5. **`stored-program-1949`**: учебная машина ровно по разделу 5 описания — восемь команд, слово =
   код × 1000 + адрес, память 128 ячеек, программа из 17 слов и данные по таблице описания.
   Показ: память таблицей (у каждой ячейки буквенная запись **и** число), регистры (аккумулятор,
   счётчик команд, регистр команды), кнопки «Такт», «Пуск», «Сброс», переключатель «10 / 100
   квадратов», который меняет только ячейку 22 и подсвечивает её. `code/squares.txt` — программа
   с комментариями и начальными данными; дословная копия в имитации по ADR 0006 (тест на совпадение есть).
   Эталон прогона (проверен интерпретатором при подготовке плана): N = 10 → таблица 0…81 в 28–37,
   161 такт, в ячейке 2 после прогона `T 38`; N = 100 → 0…9801 в 28–127, 1601 такт.
   **Добавь xUnit-тест**, который исполняет программу из `code/squares.txt` на маленьком
   интерпретаторе в тестовом проекте и проверяет эти числа: так программа для показа не разойдётся
   с тем, что видит обучаемый.
   JS машины — средство визуализации: комментарий «средство визуализации, не код эпохи».
6. **Процессы** `setup-and-run` и `fetch-execute` — по разделу 6 описания (времена, тексты,
   стоп-кадры, `detail` со строками `code/setup-sheet.txt` и `code/squares.txt`). На процессе ENIAC
   проигрыватель должен показать подписи «прошло …» — проверь вручную.
7. **`questions.json`** — шесть вопросов из раздела 7, дословно.
