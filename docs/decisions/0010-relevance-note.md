# 0010. Поле `relevanceNote` в `slice.json`: пояснение к пометке актуальности
Дата: 2026-10-19. Статус: accepted (решение автора 19.10.2026; вступает в силу при слиянии PR).

## Контекст
Brief (7.1) и спецификация оболочки требуют показывать на странице среза пометку актуальности
(а/б/в) **с пояснением**. В описаниях срезов (`docs/slices/`, раздел 4) пояснение есть, но в схеме
`slice.json` для него не было поля, и обучаемый его не видел (отчёт сессии 04).

## Решение
1. В `slice.json` добавляется **необязательное** поле `relevanceNote` (строка). Текст — из раздела 4
   описания среза, с пометкой `ЧЕРНОВИК:` до утверждения автором.
2. Оболочка показывает его рядом с пометкой актуальности; если поля нет — только пометку.
3. Валидатор: если поле есть — непустая строка.

## Последствия
- Старые `slice.json` остаются верными (поле необязательное).
- Для срезов, у которых есть описание (net-01, fe-01, fe-02, hw-01), поле заполняется сразу.
