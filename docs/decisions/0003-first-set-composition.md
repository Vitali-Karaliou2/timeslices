# 0003. Состав первого набора: трек «Компьютерные сети», сквозной пример «Справочник»
Дата: 2026-10-18. Статус: accepted (решения автора; вступает в силу при слиянии PR).

## Контекст
Brief (10.2) задаёт первый набор из шести срезов, начиная трек front-end со «Статической
страницы ~1995» с примером «пасьянс: desktop против страницы», за которой следуют
«Формы и первая динамика ~1999» и AJAX 2005. При подготовке описаний срезов выяснилось:
- у «Статической страницы» не было честного «до»: страница по функциональности не дотягивает
  до простейшей desktop-программы, а интерактивный пасьянс на статических страницах в 1995 году
  не делали — это была бы учебная конструкция;
- срез «Формы ~1999» не имел ясного «до/после»: формы и CGI существовали с конца 1993 года.
Обсуждение и варианты — в описаниях срезов `docs/slices/` и в документах проекта claude.ai.

## Решение
1. **Новый трек «Компьютерные сети» / Computer networks** (`computer-networks`) и новый срез
   **«Сеть накануне веба, около 1992»** (`net-before-web-1992`, 1991–1992): FTP и Gopher как
   способ получить документ до веба. Межтрековое ребро к `static-page-1995`.
2. **Иерархия треков** (front-end внутри веб-приложений внутри компьютерных сетей) — кандидат
   в отдельный ADR на стадии 1→n. На 0→1 вложенность выражается межтрековым ребром.
3. **Сквозной пример первых срезов — «Справочник»** (`directory`): найти телефон сотрудника.
   FTP и Gopher (1992) → страница в Mosaic (1995) → форма поиска с CGI (1995) → … → AJAX.
   «Пасьянс» вводится позже, на срезе Dynamic HTML, где он исторически честен.
4. **Desktop-программа — горизонт трека front-end**, а не «до» первого среза. Отдельная
   desktop-реализация и новый режим кода `illustrative` не вводятся.
5. **Вводимое решение «Статической страницы» — гипертекст**: ссылка внутри текста документа,
   картинка внутри текста, единый адрес для всех служб. Ссылки между машинами и запрос без
   состояния уже были в Gopher.
6. **Второй срез front-end — «Формы и CGI, около 1995»** (`forms-cgi-1995`, 1994–1996, вариант А).
   «Dynamic HTML ~1999» — первый срез после 0→1.
7. Годы `static-page-1995` — 1993–1995. Ребро `cpu-cycle → static-page-1995` удаляется.
8. Первый набор — **семь срезов**: `net-before-web-1992`, `static-page-1995`, `forms-cgi-1995`,
   `ajax-2005`, `cpu-cycle`, `punch-cards-1972`, `rup-vs-iterative-2001`.
9. **Разрешена зависимость `Microsoft.AspNetCore.Mvc.Testing`** (только тестовый проект) для
   HTTP-тестов приёмочных критериев 2 и 3.
10. **Уточнение правила анахронизмов**: проверке подлежит код и разметка, показываемые как код
    эпохи; средство визуализации (имитация терминала, проигрыватель кадров, HTML в iframe
    вокруг эмулируемого примера) — нет. `era-reviewer` запускается только на настоящем
    содержании, не на заглушках.

## Последствия
- Brief (10.2) расходится с этим ADR по составу набора; brief не правится, этот ADR главнее.
- Время автора на проверку растёт на один срез; срез net-01 делается в одной сессии с fe-01
  (общий пример), поэтому число сессий не растёт.
- Даты срезов net-01 и fe-01 проверены автором 18.10.2026 (список — в их описаниях, раздел 8).

## Отвергнутые альтернативы
- **Вариант Б для второго среза (Dynamic HTML ~1999)**: без серверного цикла «запрос — новая
  страница» у AJAX нет пары «до»; выше риск анахронизмов (браузерные войны).
- **Оба среза сразу (вариант В)**: восьмой срез в 0→1; перенесено на 1→n как «постепенный В».
- **Пасьянс из пронумерованных HTML-файлов**: так в 1995 году не делали; учебная конструкция
  выдавала бы себя за историю.
